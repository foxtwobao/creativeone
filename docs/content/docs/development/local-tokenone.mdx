## 启停与凭据

在 CreativeOne 根目录启动 TokenONE：

```bash
docker compose --env-file deploy/.env.tokenone-local -f deploy/tokenone-local.yml up -d
```

在 `/home/hulei/projects/tokenone_enhance` 启动 Enhancer：

```bash
DOTENV_CONFIG_PATH=/home/hulei/projects/creativeone/deploy/.env.enhancer-local npm run dev:api
```

必须指定该配置路径，不要直接读取 Enhancer 仓库原 `.env`，因为原配置指向线上服务。4010 的另一个 tokenlink 进程保持不变。

- 新实例管理员为 `admin@creativeone.local`，初始随机密码在 `deploy/.env.tokenone-local` 的 `TOKENONE_LOCAL_ADMIN_PASSWORD`。恢复备份后，管理员账号和密码以备份内容为准。
- 数据库密码在同文件的 `TOKENONE_LOCAL_DB_PASSWORD`，仅回环端口暴露。
- Enhancer 独立服务配置在 `deploy/.env.enhancer-local`，SQLite 保存于 `server/data/enhancer-local.sqlite`。
- CreativeOne 的 `server/.env` 已指向本地 Enhancer 和 TokenONE；内部 Secret 仅由两个后端持有。
- 上述环境文件均被 Git 忽略，权限为 600，不要公开其内容。
