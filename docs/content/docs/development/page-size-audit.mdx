# 用户页面流量巡检

已检查当前 CreativeOne 的全部前端路由，覆盖 15 个入口和身份场景。首次巡检保留为下面的基线；随后已完成移除全局 Pro Provider、全局读取去重与按需加载、生图首次加载三项优化，以及 GitHub 图标独立导入，分别以相同口径复测。未变更部署配置或依赖清单，未执行构建、类型检查和语法检查。

## 测量口径

- 每个场景使用独立浏览器上下文，关闭 HTTP 缓存，窗口为 1440 × 900，语言为中文。
- HTML、脚本、样式和本地静态资源读取实际 Vite 服务；静态流量按浏览器 Network 的传输字节累计，包含开发工具和依赖预编译模块。
- 登录、业务接口和提示词封面使用模拟数据，避免修改真实账号或调用计费模型。表中接口次数是实测请求次数，静态流量不包含这些模拟响应及封面图片。
- 另以只读数据库事务统计当前已有数据的 JSON 大小，未输出用户身份、提示词或配置内容，未抓取外部图片。
- 当前 lab 是开发服务。下面的数值不代表压缩、裁剪后的生产包，也不代表同一标签页再次访问的缓存流量。HTTP 直连和 HTTPS lab 的脚本响应均未看到 gzip / Brotli 的 Content-Encoding；依赖有 immutable 缓存，应用模块使用 no-cache。

以上是开发服务空缓存静态传输量，包含 Vite 调试依赖，未计入模拟业务响应或外部图片；不能作为生产包或真实图片流量结果。跳转入口比目标页面多一次小型路由模块请求，四舍五入后流量相同。

- 所有场景均未加载 Pro 入口；Ant Design 的全局主题、语言和 App 提示继续保留。
- 设置首次读取从 2 次降为 1 次；素材和提示词来源不再全局预载或因窗口聚焦全量刷新。素材选择、来源配置、画布相应面板及 Agent 查询在实际使用入口读取；404 不再初始化设置、素材或来源。
- 在途相同读取共用请求，写入隔开前后两次读取，继续沿用串行保存顺序；失败后释放读取状态，后续可以重试。
- 生图历史打开前请求为 0，打开后按账号、页码和搜索词使用现有 Query；灵感首次请求从 2 次降为 1 次。提示词弹窗、素材选择及原版详细设置组件按打开时加载。保留现有 Query 缓存设置及灵感 12 条页大小。
- 视频首次历史查询仍为 1 次，用于恢复进行中任务；作品分页与状态轮询继续沿用原有行为。管理员渠道和分组各 2 次的问题留待后续处理。

30 项针对性行为测试通过，包括读取去重、读取／保存顺序和失败重试。相同的 15 个冷启动场景复测无页面异常、未预期接口或失败请求；额外模拟验收历史翻页及搜索响应顺序、错误后继续搜索、提示词选择、素材分页／插入／失败重试、来源配置按需读取、弹窗明暗主题及参数保存，无页面异常或取消请求，未调用计费生成。原始结果分别保存在项目 `output/playwright/page-size-audit.json`、`output/playwright/page-size-optimized.json` 和 `output/playwright/page-size-optimized-ui.json`。停用的画布和原版参数入口未启用验收，仍需后续功能开放时验证。

## 优先处理的共用依赖

1. **全局 ProConfigProvider（已实现，待用户验收）。** `web/src/components/layout/app-providers.tsx` 原为项目唯一使用 `@ant-design/pro-components` 的位置，现有后台使用普通 Ant Design Table/Form。基线中的 Pro 开发入口约 2.99 MiB，已移除无消费者的 Provider，继续使用现有 Ant Design ConfigProvider 和全局主题；依赖清单未调整。
2. **GitHub 整包图标入口（已实现，待用户验收）。** 原为单个 GitHub 图标导入 `@ant-design/icons`，整包入口及独占图形模块合计约 1.53 MiB。已改用该图标的独立文件入口，实际减少约 1.51 MiB，Ant Design 共用图标依赖继续保留。lucide-react 开发整包另约 0.95 MiB；生产构建应验证 tree shaking，再决定是否需要导入方式调整。
3. **第二套弹层库。** ModelPicker 从 `radix-ui` 聚合入口导入 Popover，相关开发模块约 0.56 MiB，进入图像、视频和偏好页会加载。可评估复用现有 Ant Design Popover，保留模型选择器交互与主题；或改为成熟库的独立组件入口。
4. **登录与 404。** 登录页提前加载 React Router 模块约 458 KiB、中文业务语言包约 207 KiB。可将这些依赖移到登录成功后的启动流程。业务初始化已限定在用户布局内，404 不再读取设置、提示词来源及素材；公共 Provider 和布局模块仍需进一步按路由加载。
5. **停用助手的样式。** main.tsx 仍全局加载 streamdown 样式，globals.css 也扫描其代码生成样式；助手当前关闭。可以将助手专属样式放入助手模块，但优先级低于前面几项。

普通 Ant Design 共用模块约 3.57 MiB、React DOM 开发模块约 0.96 MiB，属于当前页面实际使用的依赖。应先处理明确无用的模块，再用生产构建和压缩实测它们的最终体积，不根据开发文件大小直接替换 UI 框架。
