`codex/infinite-canvas` 已完成个人画布首版代码并恢复入口，实际联调与回归见[待测清单](/docs/progress/pending-test)。本轮未执行测试、构建、类型或语法检查，也未调用真实计费模型；入口开放不代表生产部署已经验证，正式功能说明在用户确认后更新。

## 首版范围

- 按账号创建、打开、改名、删除画布，项目列表按需读取摘要，进入项目再加载节点和连线。
- 文本、图片、视频、音频素材、配置与组节点；移动、缩放、多选、连线、复制、分组、基础撤销重做及主结果选择。
- 图片生成/编辑、多结果展示、单项再次生成、视频生成与原任务查询恢复；与现有工作台共用模型能力和调用规则。
- 素材上传、插入、收藏、放大、播放、下载；裁剪、切图、视频取帧等主动编辑先上传结果再保存节点。
- 服务端校验的 ZIP 导入导出，以及保存失败后的待处理修改导出、重试和确认放弃后加载云端。

后续范围为 Agent 自动操作、文本/音频模型生成、受控插件、分享权限、实时协作和按连线自动执行，见 [TODO](/docs/progress/todo)。首版保留文字和音频素材，关闭 Agent 桥接、外部脚本加载与安装、外部节点注册和服务端插件写入口；旧记录及未知节点数据不会执行代码。

## 数据与编辑

项目保存在 `canvas_projects` 的 JSONB 中，按账号单项读取。项目、节点、连线和输出槽位的正式 ID 由服务端生成；浏览器保留关联 ID 来表达同批图操作，不能用自报正式 ID 指定持久实体。暂不拆节点表或引入 CRDT。

`canvas_project_commands` 保存操作标识、基础内容/生成版本、命令、确认结果及反向命令。浏览器串行提交局部节点/连线变更；同一操作重发返回原确认结果，标识相同而内容不同则拒绝。视口、背景等偏好单独保存，不增加图编辑版本。

服务端校验文件归属、唯一标识、悬空/重复/自引用连线和组循环。编辑以内容版本减去生成版本判断其他编辑冲突，允许仅由后台结果造成的版本前移，保护任务结果字段；其他页面的旧编辑不会静默覆盖。焦点恢复期间发生新编辑时也不自动把旧操作重定到新版本。

未确认输入、拖动和选中留在页面内存；业务数据不写浏览器数据库或本地草稿。保存失败显示真实状态，保留原命令供重试，并可导出未保存修改；放弃修改必须由用户确认。退出画布或跳转授权前等待保存成功，授权返回不会自行重新生成。

| 接口 | 职责 |
| --- | --- |
| `GET /api/projects` | 项目摘要及已删除项目标识 |
| `POST /api/projects`、`GET /api/projects/:id` | 创建或导入项目、读取单项目权威内容 |
| `POST /api/projects/:id/commands` | 版本化增量编辑及撤销/重做，操作去重 |
| 现有 `/api/ai/:channel/v1/...` 创建接口 | 携带画布关联，保存不可变请求并返回已受理任务 ID |
| `GET /api/projects/:id/task-status`、`GET /api/tasks/:id` | 轻量状态和账号所属任务结果 |
| `POST /api/tasks/:id/resume-result` | 恢复已经保存上游响应的图片文件保存，不重新生成 |
| `POST /api/projects/archive/validate`、`POST /api/files/canvas-import` | 归档结构校验及允许的媒体上传 |

## 后台任务与结果归属

图片与视频生成前先保存输出目标、引用及生成标识，保存失败不调用模型。服务端使用已保存输出节点的提示词、参数和文件引用，复核关联输入是否就绪，组装不可变请求；保留原输入、来源版本、模型、调用类型和输出关联。内部关联字段不转发上游；稳定文件地址在执行时转换为内联图片或现有签名媒体地址。

画布和工作台共用纯图片适配器、视频请求工具及 JSON 媒体执行器，不建立另一套模型能力或用户 Key。限制来源仍为共享模型配置与服务端能力校验，未登记 WAN 型号明确拒绝，不凭名称猜测能力。画布显示尺寸不会改变模型输出参数。

画布任务先进入 PostgreSQL 待执行状态，再由后台工作器领取。专用数据库会话 advisory lock 覆盖一次上游调用，执行标识限制结果提交；网络期间不持有项目或用户行锁。其他实例取得不到锁时不处理同一任务；结果事务使用持有领取锁的同一连接，原会话失去归属后无法提交结果。启动恢复不再无差别改写所有实例的 running 状态。

| 情形 | 当前处理 |
| --- | --- |
| 点击请求重发或响应丢失 | 同一生成标识返回原任务，不增加模型调用 |
| 画布任务仍处于待领取状态时重启 | 从持久待执行状态重新领取 |
| 上游调用已开始而受理状态无法确认 | 标记结果未知，不自动重发可能计费的请求 |
| 已记录上游图片响应，下载或保存未完成 | 手动恢复文件保存，复用原响应 |
| 已得到视频任务 ID | 后台沿原模型查询、下载；失败后可手动恢复查询 |
| 刷新、关闭页面或停止等待 | 后台任务继续，重新打开读取当前结果 |
| 删除目标或启动新批次 | 迟到结果保留于原任务/作品，不自动恢复目标或覆盖新批次 |
| 多结果部分失败 | 成功项保留，失败项单独处理；重新生成是明确的新任务 |

应用操作幂等不等于上游端到端恰好一次计费。停止等待不表示上游取消或退款；结果未知时再次提交明确提示可能重复计费。新视频前台仅等待读取内部任务结果，文件保存由后台完成。

上游图片响应先记录，再下载和保存文件；图片读取不到有效尺寸时不确认成功。文件写入和任务结果/画布关联完成后才显示成功；SQL 与文件卷并非同一事务资源，异常中断后依靠原响应恢复，未引用卷文件需单独核对。结果挂载仅改变对应输出字段，保护等待期间的标题、提示词、坐标与尺寸；重复终态不会重复回填。

服务端通过 music-metadata 和既有 MP4Box 读取真实媒体时长/尺寸。已登记参考时长限制按实际文件复核，需要时长而无法读取时拒绝；尚未确认的 Banana/WAN 边界继续保留 TODO，不解释为无限制。

## 撤销、归档与文件

撤销恢复已确认编辑的反向命令，不回放整张旧图。服务端检查相关对象是否仍适用，后续相关编辑造成冲突时拒绝；模型调用、费用和生成终态不属于撤销。恢复删除节点/槽位时保留可信正式 ID，并接回原任务最新状态或结果，不重新提交模型；撤销响应丢失可查回原操作。

引用清理同时检查活动画布、有效反向操作和任务请求/结果。删除画布引用不删除仍由其他记录使用的文件；主动上传替换节点媒体时解除该位置的任务关联，原作品结果保留。文件删除及引用新增沿用账号锁顺序，没有增加按年龄清理或保留期限。

ZIP 使用现有归档库，导出从已保存版本读取媒体与必要参数，剔除任务执行状态、凭据和可执行字段，重建稳定媒体地址。导入先检查结构版本、图关系、允许媒体类型及完整文件清单，再上传并创建项目；重新生成实体 ID，重映射分组、连线、提示词引用及输出槽位。未保存媒体、缺失文件及临时签名参考地址明确拒绝，不建立旧结构兼容层。

## 交互与验收

复用已有画布编辑器、主题、节点比例和可见区域裁剪，不重做编辑器。列表预览使用服务端缩略图及元数据；仅主动编辑、放大、播放、下载和导出读取原媒体。有活动任务才按现有 5 秒间隔读取轻量状态，页面隐藏暂停，结果变化后读取单项目快照。无活动任务不持续轮询，不用页面轮询驱动后台生成。

| 验收场景 | 预期 |
| --- | --- |
| 保存失败、换设备、重新打开与授权返回 | 已保存内容一致，未确认编辑不冒充已保存，不自动生成 |
| 双标签页编辑、焦点刷新及后台完成交错 | 冲突可识别，后续编辑及生成终态受保护 |
| 重复受理、任务重启与跨实例领取 | 原任务可查，不盲目重发计费请求 |
| 修改输入、删目标、换批次、多结果部分失败 | 原请求快照不变，结果归属正确 |
| 上游成功后下载/保存失败 | 明确结果未保存，恢复不重新调用模型 |
| 撤销删除、后续编辑冲突、重复导入与文件清理 | 最新结果不回退，实体和媒体引用正确 |
| 组引用、首尾帧、多模态、非法参数与缺失元数据 | 遵循已登记规则，调用前明确拒绝 |
| 跨账号 ID、旧写入口、Agent 与插件绕过 | 服务端归属校验及运行入口隔离生效 |
| 多节点、离屏媒体、明暗主题、隐藏页面 | 不预读原媒体、不依赖前台处理任务 |

具体可测试变更统一记录在待测清单，版本级归纳记录在 `CHANGELOG.md`。本轮沿用既有超时、轮询、上传限制与前端撤销条数，不新增租约、并发上限或文件保留期限。未来新增边界值前仍须说明适用环节、默认值及失败处理，并取得确认。
